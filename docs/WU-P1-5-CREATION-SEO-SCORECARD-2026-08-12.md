# WriteUrdu P1.5 — Creation Tool SEO Investment Scorecard

**Date:** 2026-08-12  
**Scope:** Card Studio, Templates, Stylish Urdu Text, Name Art, WhatsApp Status Maker, Instagram Post Maker and QR Generator  
**Purpose:** Decide which creation tools deserve active search investment after the P1.4 v2 migration.  
**Commercial model:** organic search → useful product task → additional useful page/tool depth → AdSense outside active task regions.

## Decision summary

| Rank | Route / product | Score | Tier | SEO decision |
| --- | --- | ---: | --- | --- |
| 1 | `/urdu-card-studio` | **92/100** | A — invest now | Primary creation SEO wedge |
| 2 | `/stylish-urdu-text-generator` | **86/100** | A — invest now | Second primary acquisition destination |
| 3 | `/urdu-name-art-maker` | **80/100** | B+ — strengthen | Support Stylish Text + own narrow name-art intent |
| 4 | `/urdu-templates` | **74/100** | B — support hub | Strengthen as browse/internal-link hub, not a mass-template SEO program |
| 5 | `/urdu-whatsapp-status-maker` | **69/100** | B− — selective | Keep strong product page; target maker/how-to intent only |
| 6 | `/urdu-instagram-post-maker` | **61/100** | C+ — maintain | Useful adjacent tool; no dedicated content cluster yet |
| 7 | `/qr-code-generator` | **56/100** | C — utility SEO | Maintain strong page; one Urdu/static-QR guide maximum unless GSC proves more demand |

**Immediate search investment goes to Card Studio and Stylish Urdu Text.** Name Art is the next supporting opportunity. Templates should distribute authority and help users start faster. WhatsApp/Instagram/QR remain useful products but should not compete for the same content budget until Search Console proves demand.

---

## Scoring model

The score intentionally separates observable demand from product quality. No paid keyword-volume dataset or current Search Console Devices export is available, so the score does **not** invent monthly search volumes or mobile-impression counts.

| Factor | Weight | Meaning |
| --- | ---: | --- |
| Observable search demand / intent | 25 | Active SERP competitors, adjacent app demand, and clarity of the search job |
| Fit with WriteUrdu authority | 15 | How naturally the topic extends established Urdu typing/writing authority |
| SERP attainability / web gap | 15 | Whether the web results leave a realistic opening rather than being dominated by entrenched generic platforms |
| Product differentiation / usefulness | 15 | Whether WriteUrdu can answer the query better than a thin landing page or generic generator |
| Mobile task quality | 10 | Small-screen layout, control density, preview/result prominence, overflow safety and completion flow |
| Mobile-intent fit | 5 | Whether the underlying job is naturally done on a phone |
| Useful journey depth | 10 | Ability to move users naturally between write → style/design → export/template/adjacent tool |
| Monetization + maintenance efficiency | 5 | Ability to support ad-funded growth without putting ads inside the active workspace and without disproportionate maintenance |
| **Total** | **100** | |

### Mobile evidence rule

Mobile is **15% of the score**: 10% actual task quality + 5% mobile-intent fit.

Current P1.4 browser acceptance already protects responsive creation flows on the mobile project. It checks, among other things, preview/result prominence, stacking order and horizontal-overflow safety for Card Studio, Templates, Stylish Text, Name Art, the two social makers and QR Generator. That is product-quality evidence, not traffic evidence.

A fresh Google Search Console **Devices** export is still required to measure actual mobile impressions, clicks, CTR and position by route/query. Until that exists, do not label mobile traffic percentages as measured facts.

# 1. Urdu Card Studio — 92/100 — INVEST NOW

## Query ownership

Primary route owner for:

- `urdu text on photo`
- `write urdu on photo`
- `urdu poetry on photo`
- `urdu post maker`
- `urdu poetry card maker`
- `urdu quote maker`
- `urdu poster maker online` where the intent is a lightweight browser creator

Do **not** create separate doorway pages for each wording. Card Studio should own the broad image-creation job.

## Why it wins

The strongest external demand signal in this review is not a generic `card maker` phrase; it is the mature mobile-app ecosystem around **Urdu text/poetry on photos and Urdu post/poster making**. Current Google Play results include Urdu photo/post tools with 100K+, 500K+ and 1M+ installs, while the corresponding browser SERP has far fewer strong Urdu-first tools. This is the clearest gap where WriteUrdu's existing writing authority can expand into a creation job without changing subject domain.

WriteUrdu also has a real product advantage: Roman Urdu → Urdu input, Urdu-safe fonts, local backgrounds, templates, exact social sizes and browser export are already one workflow rather than SEO copy describing a future tool.

## Mobile view

**Mobile task quality: 8/10. Mobile-intent fit: 5/5.**

The P1.4 contract keeps the Card Studio preview before controls on mobile and protects horizontal-overflow safety. The remaining mobile risk is inherent complexity: moving text, choosing templates/backgrounds and inspecting a full artboard is heavier than copying text. SEO landing improvements must therefore keep the route task-first and avoid adding large content blocks before the canvas.

## Search investment

1. Rewrite the crawlable supporting content around the broader **Urdu text/poetry on photo** job, while keeping `Urdu Card Studio` as the product name.
2. Add a concise answer block immediately after the workspace explaining that users can write Urdu on a photo, make poetry/quote cards and download locally.
3. Add 4–6 source-visible examples/use cases: poetry, quote, announcement, Eid/greeting, educational post, business notice.
4. Add reviewed FAQs around Urdu fonts, local backgrounds, mobile use, exact output sizes and privacy.
5. Create **one** supporting guide: `How to write Urdu poetry/text on a photo online` → Card Studio.
6. Strengthen links from homepage, Rich Editor, typing tutorial, font guide and Templates.

## Do not do

- no `/urdu-poetry-card-maker`, `/urdu-quote-maker`, `/urdu-post-maker` doorway clones;
- no unreviewed poetry database;
- no generic Canva-like positioning;
- no ads inside the canvas/control/export region.

# 2. Stylish Urdu Text — 86/100 — INVEST NOW

## Query ownership

Primary route owner for:

- `stylish urdu text generator`
- `urdu stylish text generator`
- `urdu name style copy paste`
- `stylish urdu name`
- `urdu text style copy paste`

Name-image intent should move to Name Art rather than being mixed into copy/paste claims.

## Why it wins

The web SERP already contains multiple dedicated Urdu stylish-text/name generators, which is strong evidence that this is a real browser search job. Competition is materially stronger than the Card Studio opportunity, but WriteUrdu has a better Urdu-specific product contract than many generic fancy-font pages: curated styles, compatibility labeling, category/intensity filtering, favourites, collections, sharing and a real handoff into image-based Name Art.

The route is also extremely compatible with mobile search behavior because the core action is type → scan results → one-tap copy/share.

## Mobile view

**Mobile task quality: 9/10. Mobile-intent fit: 5/5.**

P1.4 makes results the dominant task surface and stacks cleanly on mobile. This is one of the site's strongest phone workflows because the output can immediately move into WhatsApp, Instagram, a profile or Name Art.

## Search investment

1. Strengthen visible explanation of what is genuinely copyable Unicode decoration versus a rendered Urdu font image.
2. Add source-visible examples for names, short phrases, WhatsApp display text, Instagram bio/display name and gaming/profile use.
3. Add a compatibility-focused FAQ: why some styles render differently across phones/apps and where styled Unicode may be rejected.
4. Use Name Art as the explicit answer when users need a real Nastaliq/Naskh image rather than copy/paste text.
5. Create **one** supporting guide around `How to make a stylish Urdu name/text for WhatsApp and Instagram` with platform limitations stated accurately.

## Do not do

- no thousands of programmatic name pages;
- no claim that ordinary Urdu has a complete equivalent of Latin mathematical “fancy fonts”;
- no guaranteed rendering claims across every app/device.

# 3. Urdu Name Art — 80/100 — STRENGTHEN

## Query ownership

Own narrow image intent such as:

- `urdu name art`
- `urdu name image maker`
- `write name in urdu on image`
- `urdu name design`

Do not fight broad generic `name art maker` SERPs as the primary strategy.

## Why it scores well

Current mobile app results show substantial demand for name-art/photo-editor products, including products explicitly advertising Urdu Name Art and 1M+ installs. The intent is real, but generic `name art` is broad and noisy. WriteUrdu should win through **Urdu-specific image rendering**, not through trying to out-scale general photo editors.

Its strongest strategic role is also as the natural visual continuation of Stylish Urdu Text.

## Mobile view

**Mobile task quality: 8/10. Mobile-intent fit: 5/5.**

The v2 shell keeps the template/preset controls compact and the embedded Card Studio responsive. It is still a more complex phone task than Stylish Text, so content must not push the workspace down.

## Search investment

- strengthen the existing page rather than build a separate content cluster;
- add visible template-pack examples and explain transparent PNG use;
- add cross-links from Stylish Text and Urdu font guidance;
- test GSC demand before commissioning a dedicated Name Art guide.

# 4. Urdu Templates — 74/100 — SUPPORT HUB

## Query ownership

Own browsing intent around:

- `urdu templates`
- `urdu post templates`
- `urdu poetry templates`
- `urdu social post templates`

But the route's main value is **discovery → Card Studio**, not ranking hundreds of template URLs.

## Why it is useful

The same Urdu post-maker ecosystem repeatedly advertises ready-made templates, which validates templates as an important product feature. However a thin template-per-URL SEO strategy would create maintenance and duplication risk. The current single catalogue with 46 templates is better treated as a high-value browse hub and internal authority distributor.

## Mobile view

**Mobile task quality: 9/10. Mobile-intent fit: 4/5.**

The v2 library is particularly mobile-friendly because browsing cards is simpler than editing a canvas. Preserve fast filters and a clear `Edit in Card Studio` continuation.

## Search investment

- improve category intros only where they help users choose;
- add real visual/example metadata to catalogue cards where maintainable;
- keep one indexable library rather than dozens of thin template pages;
- link strongly into Card Studio and relevant maker routes.

# 7. QR Generator — 56/100 — UTILITY SEO

## Query ownership

Keep the current route as the owner for:

- `urdu qr code generator`
- `qr code for urdu text`
- static QR questions that genuinely involve Urdu text

Do not chase generic `QR code generator` as a primary acquisition strategy.

## Why it remains useful

The product is differentiated and technically strong: Urdu text, URL, Wi-Fi, WhatsApp, email, phone, SMS, vCard and location payloads; local logo handling; contrast/quiet-zone checks; PNG/SVG export. But generic QR generation is a mature, highly competitive category and the Urdu-specific search surface observed in this review is weak. Its greatest value is as a useful second action from WriteUrdu's editors and as a trust-building local-processing tool.

## Mobile view

**Mobile task quality: 10/10. Mobile-intent fit: 4/5.**

P1.4 keeps the QR preview first on mobile and the workflow is naturally touch-friendly. This is the best mobile implementation score in the set, but mobile UX alone does not create search demand.

## Search investment

- maintain the strong current landing page and schema;
- create at most **one** useful guide: static QR codes for Urdu text / QR quiet-zone and scanning reliability;
- strengthen contextual entry from the editors;
- revisit only if GSC shows real Urdu QR impressions.

When available, add these measured fields to this scorecard:

- mobile share of clicks;
- mobile CTR versus desktop CTR;

- route-level mobile entrances;
- query clusters that over-index on mobile.

**Decision rule:** if a Tier B/C route develops significant mobile impressions at positions 4–20, re-score it before creating new content elsewhere.

---

# Measurement gates

Do not call the Tier A investment successful merely because new content is published.

For each invested route measure:

- indexed canonical route;
- impressions and clicks by query cluster;
- mobile versus desktop CTR/position;
- editor/writing → creation handoff use where locally measurable;
- creation → template/adjacent-tool continuation;
- AdSense pageviews/viewability outside active task regions;
- Core Web Vitals / mobile overflow regressions.

Re-score P1.5 after **8–12 weeks of comparable Search Console evidence**, or earlier if a route shows a clear breakout.
