# Write Urdu public trust routes

The public trust cluster is deliberately small and factual:

- `/why-write-urdu` — who/what the project is, purpose, maintenance and correction policy.
- `/contact` — indexable direct contact route for questions, technical issues, privacy, accessibility and corrections.
- `/feedback` — noindex product-feedback utility for ideas, friction, bugs and improvements.
- `/write-urdu-privacy` — privacy, processing boundaries and terms.
- `/.well-known/security.txt` — standard security reporting contact.
- `/write-urdu-sitemap` — human-readable directory of public product, guide and trust routes.

These routes exist to make Write Urdu easier to understand, verify, contact and correct. They are not treated as a substitute for useful product pages, search relevance, external reputation or backlinks.
