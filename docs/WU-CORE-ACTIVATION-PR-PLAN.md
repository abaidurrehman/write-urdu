# Core Activation PR sequencing plan

Keep implementation reviewable and measurable. Prefer this sequence over one broad visual rewrite:

1. **PR-A Measurement** — first-value, continuation, referral and Card Studio funnels + Product Pulse reporting.
2. **PR-B Basic Writer E0/E1** — empty/first-value simplification + coherent input choices; no growth prompts.
3. **PR-C Contextual continuation** — Basic -> Rich and state-appropriate outputs.
4. **PR-D Growth arbitration** — Keep / Share / Community Publish coordination.
5. **PR-E Share continuity** — recipient CTA to destination meaningful start.
6. **PR-F Card completion** — evidence-driven quick path only after funnel diagnosis.
7. **Commercial review** — join Product Pulse with GSC + AdSense and reorder roadmap.

Each PR must name one primary metric and record the release/experiment marker used in Product Pulse.
