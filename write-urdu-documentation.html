Questions, answered

Still deciding where to begin? These quick answers cover the common cases.

Which editor should I use first?

Choose the basic editor if you prefer typing Urdu with English letters. Choose the Urdu keyboard for direct character input, or the rich editor when formatting is part of the final result.

Why did a word convert differently than I expected?

English-letter spellings can have more than one Urdu result. Try another spelling, use the suggestion list, or switch to direct Urdu keyboard input for precise characters.

Can I use Write Urdu on a phone?

Yes. The editors, controls and navigation adapt to small screens. A physical keyboard is optional; the Urdu keyboard page is useful on touch devices.

Can I come back to a draft later?

Yes. Use the draft controls to save a working copy and reopen it when you are ready to continue.
