Written steps for the current Write Urdu workflow

These steps keep the tutorial useful without sound and make the relationship between the basic editor, Rich Editor and creation tools explicit.

1

Type and review Urdu

Open the basic editor, enter Roman Urdu, press Space after a word, and review the Urdu-script suggestion before continuing. Copy the text when the wording is ready.

2

Format a longer document

Move to the Rich Text Editor for headings, lists, fonts, colour and alignment. Review the complete document before exporting.

3

Create a shareable image

Use Card Studio when the next job is a quote, poetry or social image rather than another text document.

  1. Start with a short phrase so incorrect suggestions are easy to spot.
  2. Correct names, uncommon words, numbers and punctuation before formatting.
  3. Use direct Urdu keyboard input when you need an exact character.
  4. Preview the finished document or image before downloading it.
