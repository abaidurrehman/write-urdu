A USEFUL REPORT

What to include

These details help distinguish a content issue from a browser, device or input-method problem.

01Page or tool

Tell us which editor, guide or creator you were using.

02Device and browser

For example: iPhone Safari, Android Chrome, Windows Edge or macOS Firefox.

03What you expected

Describe the result you expected to see or the action you expected to work.

04What happened

Give short reproduction steps and include only non-sensitive example text when necessary.

WHAT WE CAN ACT ON

Common feedback types

Transliteration correction

A Roman Urdu spelling produced an unexpected Urdu suggestion or conversion.

Accessibility issue

A control, keyboard path, focus state, text size or contrast makes the tool difficult to use.

Browser problem

An editor, export, QR code, image, keyboard or layout behaves incorrectly on a specific browser or device.

Practical feature suggestion

A small workflow improvement would make an existing writing or creation task easier.
