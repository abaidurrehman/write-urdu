How to type Urdu with English letters

  • Type an Urdu word using English letters in the editor above, such as mera.
  • Press Space to turn it automatically into Urdu script.
  • Paste a longer Urdu passage written with English letters, then choose Convert passage to Urdu script.
  • If the result is not what you intended, press Backspace twice and choose a suggestion.
  • Select Copy text when you are ready to paste your Urdu into another app.
  • To write "میرا خیال ہے" in Urdu script, type mera khayal hai and press Space after each word.
  • Use the same method for names and short messages, then review them before sharing.
  • For headings, colours, lists or other formatting, open the Urdu Rich Text Editor.
  • No Urdu keyboard software is required; everything runs in your browser.
  • Read the Urdu FAQ for clear answers about the language and writing system.
