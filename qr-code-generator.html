QR Generator questions

        
Can a QR code contain Urdu?
Yes. Choose Text / Urdu Text and enter the wording you want people to see. If you type Urdu with English letters, convert it to Urdu script before downloading the QR code.

        
Does the QR code expire?
No. WriteUrdu does not set an expiry date. A website or service linked inside the code can still change later.
