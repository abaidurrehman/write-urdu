19 August 2026
Clearer English to Urdu typing

The main typing page now uses simpler words

What changed

The main writer now leads with English to Urdu Typing and explains the input as English letters → Urdu. Labels and instructions no longer require you to know specialist language before you can start.

Why it helps

The page now describes the job in the same simple words people use when looking for Urdu typing: type Urdu words with familiar English letters and get Urdu script.

How to use it

  1. Open the main Write Urdu page.
  2. Type an Urdu word using English letters, for example mera.
  3. Press Space to turn the completed word into Urdu script.

Try English to Urdu typing →

18 August 2026
Share writing as a real Write Urdu link

You can publish Urdu writing to a short share link

What’s new

The Basic Writer now has a clear Share action. After you confirm publication, Write Urdu creates a short write-urdu.com/s/… link with a visual preview instead of making you send only raw text.

Why it helps

Friends or readers can open a clean page, see the Urdu writing first, then choose to use the text, make their own design or create a QR code for the shared link.

How to use it

  1. Write your Urdu in the Basic Writer.
  2. Choose Share, then Publish & get short link.
  3. Copy or share the new link. You can also delete links you created from the same browser.

See the sharing guide →

18 August 2026
Less copying and pasting between tools

Your Urdu can continue into the next tool

What changed

After you have useful text, Write Urdu now shows a small Continue with… area with relevant next steps. Depending on the page, you can continue into the Rich Editor, Card Studio, QR Generator, Text Cleaner or another suitable workspace.

Why it helps

You no longer need to remember which tool comes next or repeatedly copy and paste your writing. The current work is carried locally between supported Write Urdu pages.

How to use it

  1. Write, clean, speak or extract some Urdu text.
  2. Look for Continue with… after the result.
  3. Choose the next task, such as formatting a document or creating a card.

Explore all Write Urdu tools →

More ways to get useful Urdu text

Four new browser tools for common Urdu tasks

Fix messy Urdu text

Urdu Text Cleaner checks common spacing, Unicode and right-to-left text problems and applies conservative fixes in your browser.

Clean Urdu text →

Turn an image into editable Urdu

Image to Urdu Text reads clear Urdu from screenshots, photos and scans so you can correct and reuse the result. Clear printed text works best.

Convert an Urdu image →

Speak instead of typing

Urdu Voice Typing uses supported browser speech recognition to create an editable Urdu transcript after you choose to start the microphone.

Start Urdu voice typing →

Move older InPage text to Unicode

InPage ↔ Unicode converts supported pasted legacy Urdu text to modern Unicode and can also convert supported Unicode text back for older workflows.

Open the InPage converter →
How to use these tools: Start with the page that matches what you already have — text, an image, your voice or older InPage text — then use the suggested next step to continue writing or formatting.
