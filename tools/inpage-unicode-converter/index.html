What this converter supports

Older InPage workflows can represent Urdu characters with a legacy two-part pattern rather than modern Unicode code points. This tool recognizes the supported InPage v1/v2-style clipboard mapping, converts known Urdu letters, numerals, punctuation and common composite sequences, and leaves unknown data untouched for review.

InPage to Unicode

Paste legacy text copied from a compatible InPage workflow and convert it to Unicode Urdu. Unicode text works naturally in current browsers, messaging apps, Microsoft Word and the WriteUrdu editor.

Unicode to InPage

The reverse direction uses one documented preferred legacy byte for each supported Unicode character. Where multiple legacy bytes can represent the same Unicode mark, the converter chooses a stable preferred mapping. Characters without a confirmed reversible mapping are preserved and flagged rather than replaced with a guess.

Text conversion is not document conversion

An InPage .inp file can contain document structure, layout, fonts and other binary data beyond the character mapping. This version deliberately handles pasted text only. It does not claim to preserve page layout or open arbitrary .inp files.

Why some converted text may still need cleaning

Legacy text can contain Arabic forms, kashida, unusual punctuation or direction controls even after encoding conversion. For Unicode output you can continue directly to the Urdu Text Cleaner & RTL Fixer before editing or exporting.

Mapping profile: inpage-v1v2-clipboard-2026-08-17. The implementation is conservative: known mappings convert, unknown mappings remain visible, and the original source is never overwritten.

How to use it

  1. Choose InPage → Unicode or Unicode → InPage.
  2. Paste the source text.
  3. Select Convert.
  4. Review any unsupported-character warnings.
  5. Copy the result. Unicode output can also continue to Cleaner or WriteUrdu.

Questions

Is the converter free?

Yes. The character conversion runs in your browser and does not require a paid conversion API or an account.

Does WriteUrdu upload my text?

No. This converter does not send the source or converted result to a conversion service. Generic product telemetry must not contain the text itself.

Can I upload an .inp file?

Not in this version. The first release focuses on pasted text so the encoding behavior can remain transparent and reversible. Full .inp file parsing is a separate future feature.

Why was a character not converted?

Some InPage variants use undocumented or context-dependent byte values. The converter preserves unsupported data and reports it rather than silently substituting the wrong Urdu character.
