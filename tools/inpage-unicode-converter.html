What this converter supports

This tool converts supported Urdu text copied from common older InPage workflows into modern Unicode, and can convert supported Unicode Urdu back for older InPage workflows. Known Urdu letters, numerals and punctuation are converted; anything unsupported is kept visible so you can review it.

InPage to Unicode

Paste legacy text copied from a compatible InPage workflow and convert it to Unicode Urdu. Unicode text works naturally in current browsers, messaging apps, Microsoft Word and the WriteUrdu editor.

Unicode to InPage

Convert supported Unicode Urdu back into text intended for compatible older InPage workflows. Some characters can be represented differently in older InPage versions, so always review the result before using it in an important document.

Text conversion is not document conversion

An InPage .inp file can contain page layout, fonts and other document information in addition to the text. This tool handles pasted text only, so page layout and complete .inp documents are not included.

Why some converted text may still need cleaning

Older text can contain Arabic forms, kashida, unusual punctuation or direction controls even after conversion. For Unicode output you can continue directly to the Urdu Text Cleaner & RTL Fixer before editing or exporting.

Check the result before using it. Supported characters are converted, unsupported content stays visible for review, and your original source is never overwritten.

How to use it

  1. Choose InPage → Unicode or Unicode → InPage.
  2. Paste the source text.
  3. Select Convert.
  4. Review any unsupported-character warnings.
  5. Copy the result. Unicode output can also continue to Cleaner or WriteUrdu.

Questions

Is the converter free?

Yes. The converter is free and does not require an account.

Does WriteUrdu upload my text?

Your pasted text is used for the conversion. See Privacy for details about how Write Urdu handles data.

Can I upload an .inp file?

Not in this version. The tool focuses on pasted text. Full .inp document conversion would be a separate feature.

Why was a character not converted?

Older InPage versions and workflows can represent some characters differently. When the converter cannot safely identify a character, it keeps it visible and reports it instead of silently substituting the wrong Urdu character.
