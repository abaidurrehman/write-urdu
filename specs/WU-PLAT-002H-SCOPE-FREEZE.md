# WU-PLAT-002H — Scope Freeze

While this P0 activation phase is active, the following work should normally remain behind it in roadmap priority:

- new unrelated mini-tools;
- broad document/AI feature expansion unless an external gate is already closing and the work is independently P0;
- new export formats;
- Invoice/QR feature growth without new evidence;
- broad Urdu locale expansion beyond evidence-gated owners;
- extra community social mechanics (likes/follows/comments) before the write/read/referred-write loop works;
- new Card Studio acquisition pages before completion is diagnosed;
- another global navigation/tool-grid expansion;
- site-wide ad-density increases.

Not frozen:

- security/privacy fixes;
- production outages and regressions;
- legal/terms/flag launch decisions already required for shipped community work;
- SEO verification/recrawl and AdSense baseline tasks in `WU-GROWTH-001`;
- maintenance needed to keep current core routes healthy;
- work explicitly required to implement/measure `WU-PLAT-002H`.

The freeze ends only after the canonical backlog is re-reviewed using post-change Product Pulse + Search Console + current AdSense evidence. It does not end simply because the UI code shipped.
